What is branch and bound?

Branch and bound (B&B) is a method for optimisation problems (minimise cost / maximise profit) whose solutions form a state-space tree.

  • Branch: generate all children of a node (each child is one more decision).
  • Bound: for every node compute a number ĉ(node) that is a lower bound on the cost of any solution in its subtree (for minimisation).
  • Prune: if ĉ(node) ≥ upper, where upper is the cost of the best complete solution found so far, that whole subtree is killed — it cannot contain anything better.
