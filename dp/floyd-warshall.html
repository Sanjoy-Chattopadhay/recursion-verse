Problem 02 · all pairs, one vertex at a time

All-Pairs Shortest Paths — Floyd's Algorithm

MediumDPΘ(V³)
GFG · Floyd Warshall CSES 1672 · Shortest Routes II LeetCode 1334

Problem

Given a directed weighted graph with V vertices (weights may be negative, but there is no negative cycle), find the shortest distance between every pair of vertices (i, j). The input is the weight matrix W: W[i][i] = 0, W[i][j] = weight of edge i→j, or ∞ if there is no edge.

edges 1→2 3, 1→4 7, 2→1 8, 2→3 2, 3→1 5, 3→4 1, 4→1 2 out D = [[0,3,5,6], [5,0,2,3], [3,6,0,1], [2,5,7,0]]

Intuition

Number the vertices 1..V. Let D(k)[i][j] = shortest path from i to j that may pass only through intermediate vertices from {1, …, k}.

  • D(0) allows no intermediate vertex — it is just W (direct edges).
  • Going from k − 1 to k, a shortest path either doesn't use k (stays D(k−1)[i][j]) or goes through k once: i ⇝ k ⇝ j = D(k−1)[i][k] + D(k−1)[k][j].
  • D(V) allows every vertex — that is the answer.

Each D(k) is built from the previous one: a table filled layer by layer — dynamic programming.

Recurrence and algorithm

D(0)[i][j] = W[i][j] D(k)[i][j] = min( D(k−1)[i][j], D(k−1)[i][k] + D(k−1)[k][j] ) for k = 1..V
i

One matrix is enough — updating D in place is safe because row k and column k do not change during iteration k (D[i][k] + D[k][k] = D[i][k]).

P2How do you detect a negative cycle with Floyd's algorithm?

After the algorithm, if any diagonal entry D[i][i] < 0, vertex i lies on a negative cycle.

P3What goes wrong if you put the k loop innermost?

Then D[i][j] is finalised using D[i][k] and D[k][j] values that are not yet shortest — the DP order is broken and answers can be too large. k must be outermost.

P4For a sparse graph with non-negative weights, what is faster than Floyd?

Run Dijkstra from every vertex: V × O(E log V) = O(VE log V), better than V³ when E ≪ V². (Johnson's algorithm extends this to negative edges.)

Drawbacks

✗

Θ(V³) always — even on sparse graphs. Fine up to V ≈ 500, too slow for large graphs.

✗

Θ(V²) memory for the matrix.

!

No answer with negative cycles — it can only detect them.

!

Paths need extra work: keep a next (or predecessor) matrix to print them.
