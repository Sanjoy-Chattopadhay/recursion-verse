Problem 08 · relax everything, V − 1 times

Bellman–Ford Algorithm

Mediumshortest pathsnegative edges OKO(V·E)
GFG · Bellman-Ford CSES 1197 · Cycle Finding LeetCode 787

Problem

Given a directed weighted graph whose edges may be negative and a source s, find the shortest distance from s to every vertex — or report that a negative-weight cycle is reachable from s (then shortest paths are not defined, because you could loop forever and keep decreasing the cost).

i

The syllabus lists Bellman–Ford with Dijkstra under single-source shortest paths. Strictly, Bellman–Ford is not greedy — it never commits to a vertex early. It is the fix for exactly the case where Dijkstra's greedy choice breaks: negative edges.

Intuition

A shortest path with no cycle visits at most V vertices, so it has at most V − 1 edges.

Relax every edge once: now every shortest path that uses 1 edge is correct. Relax every edge again: every shortest path with ≤ 2 edges is correct. After V − 1 rounds, every shortest path is correct — no matter in what order the edges were relaxed.

If after that some edge can still be relaxed, a distance is still dropping — the only way is a negative cycle.

Solution technique

Set d[s] = 0 and d[v] = ∞ for every other vertex.
Repeat V − 1 times: for every edge (u, v, w), RELAX: if d[u] + w < d[v] then d[v] = d[u] + w, π[v] = u.
One more pass over the edges: if any edge can still be relaxed, return "negative cycle".
(Optimisation) stop early if a whole pass changes nothing.

Practice problems

P1A→B −1, A→C 4, B→C 3, B→D 2, B→E 2, D→B 1, D→C 5, E→D −3. Source A.

Pass 1 (in this edge order): B = −1, C = 4 → 2, D = 1, E = 1, then E→D gives D = −2. Later passes change nothing.

Final: A 0, B −1, C 2, D −2, E 1. No negative cycle.

P2A→B 1, B→C −2, C→B 1. Source A. What happens?

B→C→B has total weight −1: a negative cycle. After the 2 passes d = (A 0, B −1, C −2); in the check pass B→C still relaxes (−1 − 2 = −3 < −2) — the distances would keep dropping forever. Bellman–Ford returns FALSE.

P3Why exactly V − 1 passes?

A shortest simple path has at most V − 1 edges, and after pass k all shortest paths with ≤ k edges are correct (the path-relaxation property).

P4LeetCode 787: cheapest flight with at most K stops. How does Bellman–Ford help?

Run exactly K + 1 passes, each time relaxing from a copy of the previous distances, so a pass can extend paths by only one edge.

Drawbacks

✗

Slow. O(V·E) — on a dense graph that is O(V³). Use Dijkstra whenever all weights are non-negative.

!

No answer with negative cycles. It can only report that one exists (reachable from s).

!

Overflow: never add a weight to ∞; check dist[u] != INF first.
