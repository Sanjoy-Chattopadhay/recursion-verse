Minimum Spanning Tree — Prim's Algorithm

Mediumgreedymin-heapO(E log V)
GFG · Minimum Spanning Tree LeetCode 1584 CSES 1675 · Road Reparation

Problem

Given a connected, undirected, weighted graph G = (V, E), find a spanning tree — a subset of V − 1 edges that connects every vertex with no cycle — whose total weight is minimum. This is the Minimum Spanning Tree (MST). Example uses: laying cable / pipelines / roads between cities at the least cost.

Intuition

Start with a single vertex. The tree is one "island". To grow it, you must eventually build some bridge from the island to the rest of the graph — so build the cheapest bridge available right now. Add the new vertex to the island and repeat until every vertex is on it.

This is safe because of the cut property: for any split of the vertices into two groups (a cut), the lightest edge crossing the cut belongs to some MST. The island and the rest form such a cut.

i

Prim looks like Dijkstra. The only difference is the key: Dijkstra uses distance from the source (d[u] + w), Prim uses the single edge weight to the tree (w).

Solution technique

Set key[v] = ∞ for every vertex, key[r] = 0 for the start r. key[v] = cheapest edge joining v to the tree so far.
Pick the vertex u not yet in the tree with the smallest key; add it (with edge π[u]–u).
For every neighbour v not in the tree: if w(u, v) < key[v], set key[v] = w(u, v) and π[v] = u.
Repeat until all V vertices are in the tree.

P2Does the starting vertex change the MST weight?

No. Every MST has the same total weight. The start can change which tree you get only when there are equal-weight edges.

P3When is the MST unique?

If all edge weights are distinct, the MST is unique. With ties there may be several MSTs, all of equal weight.

P4How would you find a maximum spanning tree?

Negate all weights (or use a max-heap) and run the same algorithm.

Drawbacks

✗

Graph must be connected. On a disconnected graph Prim only spans the start vertex's component (run it once per component to get a minimum spanning forest).

!

Undirected graphs only. For directed graphs the analogous problem (minimum arborescence) needs the Chu–Liu/Edmonds algorithm.

!

Needs a priority queue for good performance on sparse graphs; with an array it is O(V²).

!

MST ≠ shortest paths. The path between two vertices inside the MST is not necessarily their shortest path.
