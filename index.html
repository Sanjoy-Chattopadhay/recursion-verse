The one big idea

Same tree. Three places to find the answer.

Every recursive solution draws a tree of choices. What changes between techniques is where the answer lives in that tree.

Recursion

Answer at the leaf

Each call carries its own copy of the partial answer (pass by value). When the input is exhausted, the leaf holds a finished answer — print it.

Dynamic Programming

Answer at the root

Children compute sub-answers; each parent combines them (max, min, sum, count). The root ends up holding the final answer — and repeated sub-problems are cached.

Backtracking

Answer in the path

One shared state is modified on the way down and reverted on the way up. The sequence of choices on the root → leaf path is the answer.
